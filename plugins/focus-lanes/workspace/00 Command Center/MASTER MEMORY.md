# Master memory

The hub. Holds only what no single project owns: cross-project rules, standing facts about how you work, and the
entity notes that connect projects. Everything project-specific stays in that project's `MEMORY.md` — this file
links to it, never copies it. Read first by any session opened at the root of the workspace. Never shown on the
dashboard page.

## How memory is organised

| Layer | Where | What goes there |
|---|---|---|
| This hub | `00 Command Center/MASTER MEMORY.md` | rules and facts that apply to two or more projects; the map below |
| Entity notes | `00 Command Center/Memory/*.md` | one note per thing shared across projects (a tool, a counterparty, a rule, a person); projects link to it with `[[Name]]` |
| Project memory | `NNN Project/MEMORY.md` | facts, people, decisions, constraints, lessons of that project only |

Rule for sessions: a fact that belongs to one project goes in its `MEMORY.md`; a fact that two projects would both
need goes in an entity note (create one if none fits) and is linked from both. When in doubt, project first.
