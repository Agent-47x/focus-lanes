# Changelog

## 0.1.0 — 2026-10

First public release.

- Lane rule: Focus (one), Test (one, time-boxed), Obligation, Enabler, Parked.
- Today: at most five tasks — up to three Focus tasks plus Obligation tasks overdue or due within three days.
- Results scorecard: Focus and Test `current / target`, days left, next deadline per Obligation, Parked review dates.
- Generated `TODAY.md`, `DASHBOARD.md` and a single-file dashboard page; an Obsidian Dataview dashboard.
- Five handoff files per project; memory hub with entity notes; domain playbooks with a capture → harvest → push loop.
- Claude plugin with three skills: `setup`, `project-status`, `daily-brief`.
- Demo workspace (seven fictional projects) and a standard-library test.
